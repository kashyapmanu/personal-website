# Personal Website

Source code for [www.manukashyap.xyz](https://www.manukashyap.xyz).

## About

A simple, fast personal portfolio site that showcases projects, experience, and contact information.

## Tech Stack

- HTML5, CSS3, JavaScript
- Static hosting

## Run Locally

Open `index.html` in your browser or serve it with any static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The site is deployed to the domain configured in the `CNAME` file.
